# mode-a-ppt-officecli · 架构

> SDD：[`spec.md`](./spec.md)

## 1. 一句话

**自建 LangChain Agent 通过 MCP Client 驱动 OfficeCLI，结合 Skill 规则生成 .pptx。**

不是 Cursor 内置 Agent 调 MCP；是独立 Python 进程（`python -m src.main`）。

## 2. 分层

```text
┌─────────────────────────────────────────────────────────┐
│  业务层    用户自然语言 → 汇报/产品/求职类 PPT 需求        │
├─────────────────────────────────────────────────────────┤
│  Agent 层  LangChain create_agent（Step 4）              │
│            system = prompts/system.md（Skill 路由表）      │
│            Skill = 运行时 officecli load_skill <matched>   │
├─────────────────────────────────────────────────────────┤
│  工具层    langchain-mcp-adapters → officecli MCP tool   │
├─────────────────────────────────────────────────────────┤
│  运行时    officecli mcp（stdio Server）→ officecli CLI  │
├─────────────────────────────────────────────────────────┤
│  产物层    output/*.pptx                                 │
└─────────────────────────────────────────────────────────┘
```

| 层 | 技术 | 职责 |
|----|------|------|
| Agent | LangChain `create_agent` | 规划、多轮 tool call、汇总回复 |
| MCP Client | `MultiServerMCPClient` | 启动 `officecli mcp` 子进程，暴露 `officecli` tool |
| MCP Server | `officecli mcp` | 接收 `command` 字符串，执行 CLI |
| Skill | 运行时 `load_skill` | OfficeCLI 领域规则（pptx / pitch-deck / morph-ppt 等） |
| Prompt | `prompts/system.md` | Agent 角色、输出目录、工作流程 |

Step 4 起调用 LLM；P0–Step 3 只验证 OfficeCLI + MCP Client + Skill 路由。

## 3. 消息流（Step 4）

```text
用户输入（python -m src.main "..."）
  → run_ppt_agent
  → async with client.session("officecli")     ← 整轮任务共用一个 officecli mcp 子进程
       → load_mcp_tools(session) → [officecli]
       → create_agent(llm, tools, system_prompt)
  → agent.ainvoke
       → astream_events 打印 [agent]/[tool] 进度（P2）
            → LLM → tool_calls → officecli(command=...) → ToolMessage → 循环
  → 最终文本（路径 + 摘要）
```

短 smoke / 单次探测仍可用 `get_officecli_tools()`；Agent 长任务用 `officecli_tools_session()`；多轮改稿用 `python -m src.main --chat`（同一 MCP session + messages 累积）。

MCP tool 参数 schema（OfficeCLI 定义）：

```json
{ "command": "officecli add /abs/path/deck.pptx '/slide[1]' --type shape ..." }
```

## 6. Skill 与 Prompt 分工

| 内容 | 读者 | 位置 | 更新方式 |
|------|------|------|----------|
| 角色、流程、输出目录、Skill 路由表 | LLM + 人 | `prompts/system.md` | 手改 |
| OfficeCLI 领域规则（排版、Delivery Gate 等） | LLM | 运行时 `load_skill` 返回 | Agent 按路由调用 MCP `officecli load_skill <name>` |

**不**在 `knowledge/` 预置静态 skill 文件；与 OfficeCLI 原生设计一致，按任务匹配 skill，节省 system token。

本地验证：`python -m src.skill_smoke` · `scripts/verify-load-skill.sh`。

## 7. Delivery Gate（Step 4 Prompt 约束）

Agent 交付前须通过 OfficeCLI 要求（摘自 MCP tool 描述）：

1. `validate <file>` — schema 无错  
2. `view <file> issues` — 无格式/结构问题  
3. `view <file> screenshot` — 视觉检查（PPT 强烈建议）  
4. `save <file>` — 落盘  

`validate` 通过 ≠ 可交付。
