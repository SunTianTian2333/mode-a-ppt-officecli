# mode-a-ppt-officecli · 能力边界

> 学习线总边界见上级 monorepo（agent-career）文档（若适用）。

## 定位

- **目标：** 自建 LangChain Agent + OfficeCLI MCP 做 PPT，作为框架化 Agent 求职 Demo
- **不是：** Cursor 内置 Agent、不是 xasp 生产集成、不是替代 mini-harness-ts

## 允许

| 项 | 路径/说明 |
|----|-----------|
| 代码 | `projects/langchain-agent-patterns/mode-a-ppt-officecli/**` |
| 项目 docs | `docs/langchain-agent-patterns/mode-a-ppt-officecli/**` |
| Spec | `docs/sdd/specs/active|done/` 下 `*mode-a-ppt*` |
| 笔记 | `learning/phase-4-langchain-patterns/**` |
| 模型 | DeepSeek / OpenAI 兼容 API |
| OfficeCLI | 本地二进制 + MCP stdio |
| 输出 | `output/*.pptx`（gitignore） |
| 读 resume-jd | 作 Demo 文案来源，不自动写回 |

## 禁止（无 Spec 扩展时）

| 项 | 原因 |
|----|------|
| 修改 `mini-harness-ts/` | 独立手搓线 |
| 修改 `deepseek-harness/` 等上游 | 只读 |
| 修改 `/home/stt/work/` | 业务仓不在本目录 |
| 依赖 Cursor `mcp.json` | Agent 自建 MCP Client |
| Web UI / HTTP 服务 | 须 Spec |
| 对接生产 OA API | mock / 本地文件即可 |
| 提交 `.env`、API Key | 安全 |
| 手改静态 skill 文件灌 system | Skill 由运行时 `load_skill` 加载；路由见 `system.md` |

## Step 范围

| Step | 允许改动 | 禁止 |
|------|----------|------|
| P0 | 环境、OfficeCLI 安装验证 | 项目代码 |
| Step 1 | 骨架、config、占位 | MCP/Agent 实现 |
| Step 2 | `mcp_client`、smoke、测试 | LLM、Skill 全文 |
| Step 3 | `system.md` Skill 路由、`skill_smoke`、测试、验证脚本 | `create_agent` |
| Step 4 | `agent.py`、`main` 入口、prompt 完善 | LangGraph、RAG、多 Agent |

Step 3 起若新增 >3 个 `src/` 文件或改 Agent 核心图，须更新 Spec AC。
